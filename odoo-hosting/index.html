Questions

Common questions.

Licensing, access, migration, backups, and billing.

Is this Odoo Enterprise or Odoo Community?

This is the open-source Odoo Community edition. It is not an Odoo Enterprise licence and does not include Enterprise-only apps. If you need those apps, use Odoo's Enterprise plan directly.

How many users can I add?

Unlimited. There are no per-user, per-module, or per-database fees on the plan.

Can I migrate an existing Odoo database?

Migration is not included by default. Email hello@carlier.site with your current Odoo version and database size to discuss whether a migration can be arranged.

Do I get root access to the server?

No. This is managed hosting. You get the Odoo application; server administration, Nginx, PostgreSQL, SSL, and monitoring are handled by Carlier.

Are backups included?

No. Automated off-site backups are an optional €240 add-on with a retention policy you choose. The base hosting plan does not include them.

Can I cancel my plan?

The monthly plan can be cancelled at any time and remains active until the end of the current billing period. For annual billing questions, contact hello@carlier.site.
